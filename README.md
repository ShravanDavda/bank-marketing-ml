# Bank Marketing — Customer Subscription Prediction

## Overview

A machine learning project that predicts whether a bank customer will subscribe to a term deposit using the Bank Marketing dataset.

## Objectives

- Explore and understand the dataset.
- Clean and preprocess features.
- Train and compare classification models.
- Tune candidate models using cross-validation.
- Evaluate the selected model using classification metrics.
- Interpret model feature importance and discuss limitations.

## Models

- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting

## Evaluation

The project evaluates models using precision, recall, F1-score, ROC-AUC, accuracy and confusion matrices.

## Repository Structure

- `notebooks/` — Main end-to-end notebook
- `data/` — Local dataset files (not committed)
- `docs/` — Study notes and project documentation
- `experiments/` — Additional experiments

## Setup

1. Create and activate a Python virtual environment.
2. Install dependencies using `pip install -r requirements.txt`.
3. Download the dataset from its documented source.
4. Place the dataset in the expected local data directory.
5. Open and run `notebooks/bank_marketing_ml.ipynb`.
